HYDROPOOL – ACTUALIZACIÓN PARA GITHUB PAGES

1. Descomprime este ZIP.
2. Sube TODO el contenido de la carpeta hydropoolpiscinas_actualizado a la raíz del repositorio nexvora-ux/hydropoolpiscinas (no subas la carpeta contenedora).
3. En GitHub selecciona Add file > Upload files y reemplaza los ficheros index.html, manifest.webmanifest, etc.
4. Comprueba Settings > Pages y selecciona Deploy from a branch / main / (root).
5. Abre https://nexvora-ux.github.io/hydropoolpiscinas/ y actualiza con Ctrl+F5. En Android reinstala la PWA si el diseño anterior sigue en caché.

Incluye 18 fotografías originales, logo original sin alteraciones y nuevos iconos de instalación.
NOTA: La cabecera se recreó en tonos HydroPool porque no se dispone del archivo original de la imagen de portada. Se mantienen el layout de dos columnas, las secciones, los botones y enlaces disponibles.
