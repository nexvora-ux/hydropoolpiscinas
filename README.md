# HydroPool Piscinas — Versión corregida

## SOLUCIÓN INMEDIATA (imagen y logo)
1. GitHub > repositorio > archivo `index.html` > editar (lápiz).
2. Reemplazar TODO el contenido por el del `index.html` de este paquete; haz commit.
3. Actualizar el navegador con Ctrl+F5, o en el celular abrir incógnito para evitar caché.

La piscina y el logotipo están incrustados en el HTML, por lo que no dependen de la carpeta `assets`. También se incluye CSS y JavaScript en el mismo archivo.

## PARA QUE WHATSAPP MUESTRE EL LOGOTIPO Y LA PWA SEA INSTALABLE
Sube asimismo `assets/`, `manifest.webmanifest`, `sw.js` y los iconos, conservando exactamente los nombres y las carpetas. En GitHub, **Add file > Upload files** puede subir arrastrando la carpeta `assets` completa junto con los demás archivos.
